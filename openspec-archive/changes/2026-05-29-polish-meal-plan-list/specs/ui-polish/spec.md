## UI Polish: Meal Plan List Page

### Requirements

- R1: Cards verwenden `border-l-4 border-l-primary` als visuellen Akzent
- R2: Desktop-Layout zeigt 2-Spalten-Grid (`md:grid-cols-2`)
- R3: Header zeigt aggregierte Stats (Anzahl Pläne, Gesamtmahlzeiten, Gesamtportionen)
- R4: Card-Aktionen (Löschen) sind in einem DropdownMenu (⋮) versteckt
- R5: Create-Form ist ein shadcn Dialog, kein inline-Collapse
- R6: Vertikale Abstände sind reduziert (kompakter)
