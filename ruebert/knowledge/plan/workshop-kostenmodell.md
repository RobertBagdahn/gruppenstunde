# Workshop: Zahlen für die Kostenabwägung

## Kurzfassung

Die Kostenlogik ist entschieden (Überbestand: Kapital, Lager, MHD-Entsorgung; Fehlbestand: direkt, Kombi, Ranking). Die Zahlen werden im Workshop erarbeitet.

## Inhalt

- [Fehlbestand (je Tag bzw. Woche ohne Bestand)](#fehlbestand-je-tag-bzw-woche-ohne-bestand)
- [Überbestand (je Tüte, die nicht rechtzeitig verkauft wird)](#überbestand-je-tüte-die-nicht-rechtzeitig-verkauft-wird)
- [Fragen zur Abwägung](#fragen-zur-abwägung)
- [Vorbereitung](#vorbereitung)

**Status:** Daniels Kostenlogik ist entschieden (5B, 6C). Die Zahlen werden **im Workshop gemeinsam erarbeitet**. Bis dahin rechnet das Tool die Abwägung nur qualitativ.

Ziel: Für jede Position einen Wert oder eine grobe Näherung festlegen. „Grob, aber begründet“ reicht – Genauigkeit kann später aus Daten verbessert werden.

## Fehlbestand (je Tag bzw. Woche ohne Bestand)

| Position | Was wir brauchen | Möglicher Ansatz | Wert im Workshop |
|---|---|---|---|
| Entgangener Direktverkauf | Deckungsbeitrag je Tüte, getrennt Eigen-/Fremdmarke | VK netto − EK − Gebühren (z. B. Amazon) | |
| Entgangene Kombi-Verkäufe | Anteil Warenkörbe mit weiteren Artikeln, Ø Zusatz-Deckungsbeitrag | Schätzung Daniel oder Auswertung Auftragsdaten | |
| Ranking-Verlust | Wie lange dauert die Erholung nach einem Ausverkauf, wie viel Absatz fehlt in dieser Zeit? | Erfahrungswert Daniel (z. B. „X Wochen mit −Y %“) | |
| Saisonfaktor | Ist ein Ausverkauf im Peak (März–Mai) teurer? | Multiplikator für Peak-Wochen | |

## Überbestand (je Tüte, die nicht rechtzeitig verkauft wird)

| Position | Was wir brauchen | Möglicher Ansatz | Wert im Workshop |
|---|---|---|---|
| Kapitalbindung | Zinssatz / Opportunitätskosten pro Jahr | z. B. % vom EK pro Jahr | |
| Lagerkosten | Kosten pro Tüte bzw. Palette und Monat | Lagerkosten ÷ Bestand | |
| Entsorgung vor MHD | EK der entsorgten Ware + Entsorgungskosten | EK + Pauschale | |
| Kurze Resthaltbarkeit | Ab welcher Restlaufzeit leidet der Verkauf, und wie stark? | Schwelle in Monaten + Abschlag | |

## Fragen zur Abwägung

1. **Verhältnis:** Wie viele Tüten Überbestand ist dir ein vermiedener Ausverkauf eines typischen Artikels wert?
2. **Unterschiede:** Gelten für Topseller, Nischenartikel und Fremdmarken andere Werte?
3. **Mindestbestellwert:** Ab welchem Fehlbestandsrisiko soll das Tool trotz Regel 1A (warten bis 100 € netto EK) einen Warnhinweis zeigen?

## Vorbereitung

- Daniel: grobe EK/VK je Kategorie, Amazon-Gebühren, Lagerkosten, Entsorgungsmengen der letzten Jahre, Erfahrungswerte zum Ranking.
- Robert: aus der Datenbasis Ausverkaufshäufigkeit und Peak-Anteile vorbereiten, sobald der Zugriff steht.
